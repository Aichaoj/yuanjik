# 天元衡 · 个人健康节律预测内核

> **体系代号**：天元衡（TianYuanHeng）　**引擎版本**：`TYH-ENGINE-0.1.0`　**规则版本**：`TYH-RULES-1.0.0`（冻结于 2026-10-06）
> 本内核是《元健康 AI 顾问》的计算内核，实现**四步模型**：`编码 → 场谱 → 偏移 → 对冲`

---

## 一、这是什么

一套**完全确定性**的个人健康节律计算内核。输入「出生日期时间 + 出生地经纬度」，输出「今日十二脏腑通道的节律偏移与观察等级」。

**算法全部建立在公有领域知识之上**：《黄帝内经·素问》运气学说（五运六气）、干支历法、二十四节气、藏象学说、子午流注。
**不包含、不参考任何第三方未公开的算法、映射表或命名体系。**

---

## 二、三条不可动摇的设计约束

| # | 约束 | 为什么 |
|---|---|---|
| **1** | **完全确定性**：同一输入 + 同一规则版本 → 同一输出 | 任何人都能用一本万年历验证我们。**历法算错是最尴尬也最致命的失败**——错一次，整个系统可信度就没了 |
| **2** | **所有输出必须可反查**：每个结论都能回溯到 `规则ID + 古典条文出处 + 参数 + 输入` | 不可解释的输出**不允许上线** |
| **3** | **合规护栏是最后一道卡口，不可绕过** | 内核只产出结构化事实，对外措辞由护栏统一生成 |

## 三·补、八维数值体系（`dimensions.py`）

| 维 | 名称 | 经典依据 | 校标标准 |
|---|---|---|---|
| **T** | 时间维 | 《素问》运气七篇 · **《伤寒论》六经欲解时** | 紫金山天文台节气数据 |
| **C** | 禀赋维 | 《灵枢·阴阳二十五人》五行骨架 | 国标《中医体质分类与判定》九种体质 |
| **S** | 状态维 | 藏象 · 子午流注 | 常规体检客观指标 |
| **L** | 六经维 | **《伤寒论》六经辨证 · 八纲** | 中医师辨证结论 |
| **B** | 行为维 | 《素问·举痛论》「百病生于气也」「劳则气耗」 | 行为日志 |
| **P** | 心理维 | 情志学说 + 现代心理测量 | PHQ-9 / GAD-7 / PSQI |
| **R** | 关系维 | 社会支持与健康研究（Cohen & Wills 1985） | 社会支持量表 |
| **W** | 事业维 | Karasek 需求-控制 · Siegrist 付出-回报 · IARC 夜班 2A | JDC / ERI 标准问卷 |

**耦合算子（规则 MD-005）**：社会-心理因素**不直接产生健康分量**，而是改变敏感度与恢复速率：
```
S(t) = S₀ + A·(1 + κ_R·r + κ_W·w)·D(E(t)) − B·R(t)/ρ
```
- **★「无信息 = 无耦合」**：量表中点时 r = w = 0，敏感度 = 1.0（此为零点设计，见下"已修复缺陷"）
- **★ 明确排除**：不使用配偶生辰做「合婚」式耦合——无法证伪，按 YJ-001 不进入数值模型

**★《周易》取舍（规则 YJ-001）**：《周易》只取**阴阳二元结构与象数分类思维**；**八卦、六十四卦、卜筮推断一律不进入数值模型**。单元测试 `test_no_bagua_in_engine_symbols` 会扫描引擎源码强制此约束。
> 理由：卜筮内容无法证伪，一旦纳入，整个多维体系的测量学性质即被污染，权威机构考评必然不通过。

**文献登记（`LITERATURE`）**：5 条可溯源引用（Karasek 1979 / Siegrist ERI / IARC Vol.124 夜班 2A / Cohen & Wills 1985 / CHS 社会支持前瞻研究）。
**引用纪律**：只做方向性引用，**严禁因果升级**——IARC 2A 是"可能致癌"，不得写成"夜班致癌"（caveat 已与文献绑定在代码中）。

```
① 编码  build_birth_chart()   四柱（年柱以立春为界 / 月柱以节气为界 / 日柱 JDN 模 60 / 时柱五鼠遁）

```

## 六、★ 三条最高危的规则（错了会静默地把全体用户算反）

### 1. 太过之运「所胜受病」——受病主脏不是本脏

> 依《素问·气交变大论》：**「岁木太过，风气流行，脾土受邪。」**

**太过之运的受病主脏 = 本运所克之脏（所胜）**，本脏为次。
例：**木运太过 → 脾土为主、肝为辅**。

若按"本气自病"建模，**全体用户输出方向系统性反向**，且不报错、不崩溃。
→ 见 `rules.py` **YQ-014**、测试 `test_taiguo_shi_suo_sheng_shou_bing`

### 2. 君相二火是特例——不能按五行同气判

> 依《素问·六微旨大论》：**「君位臣则顺，臣位君则逆。」**

少阴君火（客）加临少阳相火（主）= **君位臣 = 顺**；反之为 **逆**。
二者同属火，**纯按五行会误判为"同气"**，分值偏差约 0.20 —— **足以改变排序**。
实例：2026 丙午年三之气正是这个组合。60 年周期内共 **20 处**此类特例。
→ 见 `rules.py` **YQ-007**、测试 `test_rule_jun_wei_chen_special_case`

### 3. 「主胜逆，客胜从」——生克方向极易反过来

> 依《素问·至真要大论》：**「主胜逆，客胜从，天之道也。」**

客气克主气 = 客胜 = **顺（从）**；主气克客气 = 主胜 = **逆**。
→ 见 `rules.py` **YQ-006**（含纠错记录）、测试 `test_rule_zhu_sheng_ni` / `test_rule_ke_sheng_cong`

> **由此确立铁律**：每一行规则都必须有**古典条文出处 + 单元测试 + CI 断言 + 中医师签署**。

## 八、合规护栏

**三层拦截，顺序不可颠倒**（`guard()`）：

1. **对原始文本做硬拦截扫描** —— 必须在措辞替换**之前**
   > ⚠️ 初版把替换放在扫描前，导致「确诊」被替换成「自查」而**绕过拦截**（测试 `test_blocks_diagnosis_words` 抓出此漏洞，已修复）
2. **措辞软化**（风险等级→观察等级 / 高风险时段→节律波动较明显时段 …），**再扫一遍**防替换引入新问题
3. **追加免责声明与 AI 标识**（幂等，重复调用不会叠加）

**禁用词五类**：诊疗疗效类 · 疾病风险断言类 · 绝对化夸大类 · 心理治疗类（国卫医政发〔2026〕8 号）· **常见疾病名 + 疾病名正则兜底**

**固定合规话术**：`DISCLAIMER`（非医疗器械声明）· `AI_NOTICE` · `REFERRAL`（就医引导）· `CRISIS_NOTICE`（危机热线）· `refuse_out_of_scope()`

> ⚠️ 上线前必须**人工复核危机热线号码的有效性**；护栏词表须经法务评审并持续更新。

1. **护栏绕过漏洞**：初版把「措辞替换」排在「禁用词扫描」之前，导致「确诊」被替换成「自查」而**绕过拦截**。已改为先扫原始文本。（被测试 `test_blocks_diagnosis_words` 抓出）
