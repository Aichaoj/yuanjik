## 五、踩过的坑（别重复）

1. **IIS 未开 gzip**：`app.js` 377 KB 原样下发 → 大件必须按需加载（`cities-x.js` 77 KB 只在档案/家人表单时取）。
2. **载荷 ASCII 闸门**：载荷脚本里出现中文注释会被拦下（不报错、只是没上线），改 ASCII 再投。
3. **家人出生地反查**：先认区县（0.05°≈5.5 km）再退市级；只按市级 0.12° 必失败（v55 实测栾川离洛阳 0.84°）。
4. **图片缓存**：`img.yuanjk.cn` 前有 IIS 代理 `yjk-img-proxy`，换图后要 `?v=<时间戳>`。
5. **测试数据**：用完必须用同一令牌自证清理（令牌一换就找不回）。
6. **重复记账**：L2 落变更单/报告、L1 落部署记录，同一变更只记一处。
7. **累计值不能当事实**（2026-10-24 实证）：`baseline.observation_count` 是可被重置的计数器，
   `checkin` 表（按日一行）才是签到天数的唯一事实源。v56 起 `_heal_baseline_count` 每次签到/读节律都按明细校准（只升不降）。
8. **整行 upsert 的接口不能半字段调用**（2026-10-24）：`POST /v1/healthscore/save` 是整行覆盖，
   只传 diet/mood 会把吸烟/运动/血压等清成"未知"；必须**先 `GET /v1/healthscore/status` → 合并 → 再写**。
9. **静默通道的载荷只认 `.txt`**：直接上传 `.ps1` 到 img.yuanjk.cn，agent 会把字节写成 `36 69 114 …`；
   dpaste 链接会被 agent 以 HTTP 400 拒收（2026-10-24 两次实测）。
