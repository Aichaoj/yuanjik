## S1 · 上线部署工程师

- **专业**：本机构件经静默通道上线、备份、回读、回退。
- **触发**：任何要落到线上 `shuzi.yuanjk.cn` / `admin.yuanjk.cn` / 主站的动作。
- **输入**：变更单（L2+）或 L1 三行记录、待上线的文件清单、回退点。
- **产出**：`变更记录\<日期>_<主题>_上线报告.md`（含实测表、回退命令、未验证项）。
- **验收**：`CRIT_FAILURES=0`、`EXIT=0`、回执 `match=True`、`SERVICE=Running`；
  **线上回读**（HTTP 200 + 字节数 / 关键词）与本地一致；`_tool_ver_consistency.py --live` PASS。
- **禁区**：不改服务器上别的站点；不碰线上库数据（除批准过的定向清理）；高峰窗不跑 AI 接口批量作业（铁律二十）。

## S2 · 数显前端工程师

- **专业**：`shuzi\web\`（`index.html` / `app.js` / `cities*.js` / `admin\`）交互与适配。
- **触发**：数显站任何界面、表单、建档、家人、身体数据、档案屏改动。
- **输入**：`shuzi\_verify_v<NN>\` 里的既有测试；需求口径；旧版回退文件。
- **产出**：改后的 `web\` 件 + 新增/更新的验收脚本 + 版本号（`app.js` 三个常量 + `version.json` 同步）。
- **验收**：真浏览器用例全 PASS 且**无真正 JS 报错**；手机端 390×844 与桌面各验一次；
  **至少一项真机未验的要写进报告**（不许写成已验）。
- **禁区**：首屏不许无谓增重（`cities-x.js` 那类按需加载的做法为准）；不给线上堆未使用的大文件。

## S3 · 服务端与数据工程师

- **专业**：`服务端\`（适配层）、`shuzi\server\`（服务）、`state.db` / PG、接口契约。
- **触发**：接口新增或语义变化、持久化、登录态、家庭席位、评分落库。
- **输入**：`服务端\接口契约v0.md`、`服务端\基线契约.md`、现有接口实测样本。
- **产出**：接口实现 + 回读样本 + `变更记录` 里的一节（含错误码语义）。
- **验收**：既有接口**路径/参数/响应形状零变更**（除批准项）；新接口回读 200 且字段齐全；
  登录/换设备/清缓存场景各验一次。
- **禁区**：不静默换号；不把测试账号留在库里（用完同一令牌自证清理）。

## S4 · 中医内核与规则工程师

- **专业**：`核心\tianyuanheng\`（运气 / 藏象 / 时相 / 规则注册表）、`核心\规则清单.md`。
- **触发**：评分口径、权重、条件扣分、时辰/节气/干支逻辑、规则版本升级。
- **输入**：`方案\07_多维数值体系与考评验证方案.md`、`方案\种子_六十甲子运气表.md`、`_tool_bump_rules.py`。
- **产出**：规则变更 + 规则版本号 + 回归结果（前后分数对照表）。
- **验收**：确定性（同输入同输出）；缓存键含规则版本；旧结果失效路径说明清楚；
  改变分数的必须给「谁的分变了、变了多少」的实测表。
- **禁区**：不出现病名、不做诊断式表述（术语黑名单 0 命中）。

## S5 · 合规与申报工程师

- **专业**：`方案\`、`申报\`（软著 11+ 件、专利 5 件、附图）、器械边界、PIPL 口径。
- **触发**：对外文案、软著/专利材料、隐私与同意流程、体检/设备数据接入表述。
- **输入**：`文档\` 里的合规复核报告、`申报\` 既有件、术语黑名单。
- **产出**：定稿文件 + 一份「与既有口径是否冲突」的自检表。
- **验收**：术语黑名单 0 命中；不把功能说成诊断/治疗；引用的法条与标准号可核；
  无法核实的**写进「未能核实清单」**，不写成结论。
- **禁区**：不对外承诺"治愈/替代就医"；不在公开材料里放真实用户数据。

## S6 · 凭据与安全工程师

- **专业**：凭据引用化（`_zfcred.py` 取值唯一入口）、脱敏盘点、入柜与复扫。
- **触发**：任何要写口令/密钥/令牌的场合；部署前加固；技能档案清理。
- **输入**：`_zfcred.py`、`_tool_cred_mask.py`、`_tool_cred_vaultize.py`、`_tool_skill_audit.py`。
- **产出**：引用名（`vault:<名>`）+ 脱敏扫描输出 + 改动前后哈希。
- **验收**：全工作区复扫 0 命中明文；`.agent\` 与 `_资料\` 不入库（`.gitignore` 生效）。
- **禁区**：口令/密钥不写进文档、脚本、聊天、提交信息；不动 `.agent\` 下的私钥。

## S7 · 文档与变更留痕官

- **专业**：`变更记录\`、`文件目录.md`、分级留痕（L0/L1/L2/L3）、`_tool_append_md.py`。
- **触发**：每次改动收工；新增目录/文件；对外交付文档。
- **输入**：本次改动清单、验收证据、备份位置。
- **产出**：变更单或上线报告；`文件目录.md` 增行（新目录必须登记）。
- **验收**：能回答四问——改了哪几件、证据是什么、回退一条命令是什么、哪些没验；
  `acceptance` 逐条有留痕；**同一变更只在一处记账**（L2 落 `changes/json`，L1 落部署记录）。
- **禁区**：不写"应该/大概"；两处重复记账；不留空「未验证项」。
