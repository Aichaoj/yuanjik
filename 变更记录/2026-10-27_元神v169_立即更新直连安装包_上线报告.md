# 元神 v169：「立即更新」直连安装包（不再跳外星人商店页）

- 师父反馈（2026-10-27）：「APP 只有检查更新，后面出现立即更新，点它怎么跳到外星人应用了，没有直接转到 installer。」
- 版本：web **168 → 169**（部署迭代 **v181**）；APP 仍 1.1.2（本次只改 H5 逻辑，不用重打 APK）
- 线上：<https://shuzi.yuanjk.cn>（web=169，`?v=20261027b`）

---

## 一、根因

`app.js` 的「立即更新」写的是：

```js
if (n.app && ver.latest && ver.latest.apkUrl) {
  window.open(ver.latest.apkUrl, '_blank');
}
```

- `version.json.apkUrl` = **`https://wxr.arpa.cc/zh/store`**（商店页），所以跳到了外星人应用/商店；
- 真正的安装包在 **`version.json.apk.url`** = `https://wxr.arpa.cc/api/apps/<id>/installer`，代码完全没用它。

## 二、改法（app.js `verUpdate()`）

优先取 `ver.latest.apk.url`（installer），并按运行环境分流：

| 环境 | 点击「立即更新」 |
|---|---|
| 原生壳（有 `window.YJK.installUpdate`） | 调 `YJK.installUpdate(installer, sha256)` → **后台静默下载**，不再打开浏览器/商店 |
| 浏览器 H5 | 直接 `window.open(installer)` → **直接下载 APK** |
| 只有网页版本更新 | 仍带 `?v=` 整页重载 |

`apkUrl`（商店页）只作为没有 `apk.url` 时的兜底，不再作为首选。

## 三、验收（公网 9/9）

用假的新版本（app=1.1.3）驱动页面，两种环境分别点「立即更新」：

```
[PASS] 有新版本时出现「立即更新」
[PASS] 浏览器「立即更新」直连 installer
       opened=['https://wxr.arpa.cc/api/apps/59ae85dd…/installer']
[PASS] 没有跳到商店页
[PASS] 原生壳「立即更新」调用 installUpdate(installer, sha)
[PASS] 原生壳内不打开商店/浏览器    opened=[]
```

另：线上 `web=169`、`app=1.1.2`、`apk.url=installer`、更新说明仍无「师父」字样。

部署回执（v181）：`ASSET_TOKEN_B=6`、`VERSION169=True`、`JS_UPDATE_DIRECT=True`、`CRIT_FAILURES=0`、`EXIT=0`、`SERVICE=Running`。

## 四、说明

- 本次**没有重打 APK**：1.1.2 的安装包不变，改的是 WebView 载入的 H5 逻辑，所有 1.1.2 用户下次打开即生效。
- 原生壳内仍是「后台静默下载 + 系统安装确认一次」；浏览器直接下载 installer 后由系统安装。
- 真机上「点立即更新 → 下载 → 安装」未实际跑（本机无真机），需要师父在手机上点一次。
