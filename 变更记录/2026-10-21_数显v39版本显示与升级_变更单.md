# 变更单 · 数显 v39：APP 右下角版本显示 + 升级提示

- 日期：2026-10-21
- 等级：**L2**（新增前端组件 + 新增静态数据文件 `version.json`；服务端接口零改动）
- 提起：师父令（2026-10-21 21:53 起）
  > 「现在的元神APP右下角需要增加APP版本显示及提示升级」
- 口径确认（师父已选）：
  1. 版本显示 = **站版本 + APP 包版本都显示**；
  2. 升级提示 = **启动静默检查，有新版亮红点 + 一次性提示，点「立即更新」自动刷新**

## 一、要做什么

| # | 内容 |
|---|---|
| 1 | 新增 `web/version.json`：站版本 `39`、包版本 `1.0.0`、构建日、更新要点、APK 下载地址 |
| 2 | 右下角常驻小徽标：`APP 1.0.0 · v39`；有底栏页面浮在底栏上方，二级页贴右下角 |
| 3 | 点徽标 → 「版本与更新」抽屉：包版本 / 网页版本 / 构建日期 / 最新版本 / 更新要点 / 检查更新 / 立即更新 |
| 4 | 启动后静默拉 `version.json`（`no-store` + 时间戳，不阻塞首屏）：服务端更新 → 亮红点 + 同版本只提示一次 |
| 5 | 「立即更新」= 清缓存刷新到新版；包版本更高时改为打开 APK 下载地址（走壳的站外跳浏览器逻辑） |

**技术边界（必须写清，不许含糊）**：现有 APK 壳**无 JS 桥、未改 UA**，网页读不到自身包版本；
因此「APP 1.0.0」是**本页发布时登记的包版本**（与 `version.json` 的 `app` 同步），
不是从系统读到的值。要读真值需下次打壳时给 UA 加标记（跨工作区，另行请示）。
