# 元神 v195 上线报告：登录框自动带出上次登录的手机号

- 日期：2026-10-29 13:22（部署迭代 **v195**）
- 版本：web **v195**（`app.js` / `index.html` / `version.json`）
- 触发：师父令「上次用户使用登录过的手机号，自动在登录框显示，便于自动登录」

## 一、做法

| 点 | 实现 |
|---|---|
| 记什么 | 登录成功（或注册成功）时，把这次用的账号写进本机 `localStorage['yh.login.last']`（手机号或昵称，只在本机） |
| 何时带出 | 每次打开「登录」面板：本地有记录且输入框为空 → 自动填入；同时提示「已带出上次登录的账号：139****9000」 |
| 便于登录 | 焦点直接落在**密码框**；密码仍留空（灰字 Aa123456）⇒ 点一下「登录」即可。上次用自定义密码的，只需补输密码 |
| 换号 | 直接改手机号输入框；登录成功即覆盖记录。注册成功后也记录该号，回到登录即带出 |
| 打码 | 提示里只显示 `138****8000`；完整号码只出现在输入框里（本机数据，不上传、不外显） |
| 边界 | 不自动提交登录（避免代用户决策/误登他人账号）；未登录态与已登录态互不影响 |

## 二、验收（23/23，可复跑）

- 静态：`K_LAST_LOGIN` 存在；登录/注册两处成功分支都写入（2 处）；`openAuthSheet` 带出并把焦点给密码框；打码函数存在。
