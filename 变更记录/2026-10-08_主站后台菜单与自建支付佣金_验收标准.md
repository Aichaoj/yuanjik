## 二、自建支付与佣金账本（师父定：**按实付金额 × 30%**）

### 分期（**必须先说清哪些要资质**）
| 期 | 内容 | 前置 |
|---|---|---|
| **P1（本期做）** | 订阅商品与订单模型、下单/查单接口、支付回调**端点骨架**（验签留空位）、**佣金账本**（实付 × 30%）、用户端订阅页、后台订单与佣金视图 | 无（不碰真钱） |
| **P2（等商户号）** | 接微信支付 / 支付宝：下单、支付、退款回调、对账 | **支付商户资质**（营业执照、对公账户、商户号、API 证书/密钥 → 走 `vault:` 引用，绝不入代码） |
| **P3（需合规）** | 佣金结算与提现（门槛、T+7、税务代扣） | 资金合规与税务方案；**须避免二清**（不得替用户沉淀/清分资金） |

### P1 接口（新增）
```
GET  /api/v1/subscribe/plans                订阅套餐（月/季/年，价格字段留配置）
POST /api/v1/subscribe/order    {plan_id, idempotency}  创建订单 → {order_no, amount, status=created}
GET  /api/v1/subscribe/order/{order_no}      查单
POST /api/v1/pay/callback/{channel}          支付回调端点（P1 只做骨架：验签位 + 幂等 + 落库）
GET  /api/v1/me/commission                   我的推广收益（累计/待结算/已结算/明细）
GET  /api/v1/admin/commission?page=          后台佣金流水（独立后台用）
```

### 数据（沿用 state.db）
```
sub_plan(plan_id, name, days, price_cents, active)
sub_order(order_no PK, member_id, plan_id, amount_cents, paid_cents, status, channel,
          paid_at, refund_cents, created_at, idempotency_key UNIQUE)
commission_ledger(id PK, order_no, referrer_member_id, referee_member_id,
                  base_cents, rate_bp, amount_cents, status, reversed_cents,
                  settled_at, created_at, UNIQUE(order_no, referrer_member_id))
```

### 佣金规则（**师父已定：实付金额 × 30%**）
- 计佣基数 = 订单**实付金额**（`paid_cents`，非标价、非毛利）；
- 比例 = **30%**（`rate_bp=3000`，写成常量便于日后调）；
- 每次**支付成功**（含**续费**）都计佣，**同订单号幂等**（不重复）；
- **退款冲正**：整单退 → `reversed`；部分退 → 按比例冲减 `reversed_cents`；
- **自推自买拒绝**（同 member / 同设备）并标记人工复核；
- 结算：`pending → settled`（T+7，过退款期）；**提现 P1 不开放**（按钮置灰 + 说明）。
- **合规自检**：仅**一级分销**、按**实际成交**计佣、**无入门费/无按人头收费**（脚本 + 文档双断言，避传销红线）。

### 验收标准（P1）
| # | 标准 |
|---|---|
| 1 | 下单幂等：同 `idempotency_key` 重复请求只产生 1 张订单 |
| 2 | 支付回调（模拟）后订单 `status=paid`；**同一回调重放不重复计佣** |
| 3 | 佣金金额 = `round(实付 × 30%)`，逐分比对（如 19900 分 → 5970 分） |
| 4 | **续费**订单同样产生 1 条佣金，不与首单合并 |
| 5 | 全额退款 → 该笔佣金 `reversed`；部分退款 → `reversed_cents` 按比例 |
| 6 | 自推自买 → **不计佣**并落人工复核标记 |
| 7 | 无推荐人的订单 → 不产生佣金（不报错） |
| 8 | 用户端可查收益明细；后台可查全量流水（分页） |
| 9 | 回调**验签位**存在且默认**拒绝未签名/签名不符**的请求（P1 用占位密钥，P2 换真证书） |
| 10 | 既有接口与测试零回归（社交 51 / 内核 335 / 服务端 104） |
