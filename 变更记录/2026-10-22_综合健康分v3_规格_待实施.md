## 二、打分留痕（这次必须做到，否则分数是玄学）

新表 `score_snapshot`：

| 字段 | 含义 |
|---|---|
| `id` | 快照 id |
| `member_id` | 会员 |
| `score` | 本次综合分（0–100） |
| `prev_score` | 上次综合分（用于显示变化） |
| `parts_json` | 六维度各自分数与权重、是否 used |
| `inputs_json` | 本次用到的输入：问卷 id/题号/取值、亲密关系取值、时空分来源 |
| `rule_version` | `score-v3.2026-10-22` |
| `created_at` | 时间 |

**铁律**：
1. 没有任何新输入 → **分数不变**，并返回 `unchanged:true` 与「本次未变，因为没有新依据」；
2. 每次变化必须能回答「哪一项输入、从多少到多少、占多少权重」；
3. 时空分无法取得（内核不可用/无档案）→ 该维度标 `used:false`，其余维度**按有效权重重新归一**，界面写明"时空节律未参与"。

## 三、可验证的验收标准

| # | 判据 | 验证方式 |
|---|---|---|
| A1 | 六维权重之和 = 1.00，且与上表一致 | 接口返回 `weights` 求和断言 |

| A5 | 时间分取自内核当日分，不由前端传入 | 直接改前端参数，分数不受影响 |
| A6 | 快照可回放：按 `inputs_json` 重算得到同一 `score` | 单元测试 |
| A7 | 未成年/无档案：两性维度未参与，权重归一 | API 断言 |
| A8 | 页面明示"不诊断/不预测" | 前端文案检查 |
