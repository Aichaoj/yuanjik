## 四、改动二：协议站深链白屏（不改这处，改动一等于没做）

**现象**：`https://agreement.yuanjk.cn/merchantSettled/two` 页面**全白**（`#app` 为空）。

**根因（实测）**：`index.html` 里用的是**相对路径** `./assets/index-D51PlIMn.js`。深链 `/merchantSettled/two` 下浏览器会把它解析成 `/merchantSettled/assets/…` → IIS 没有这个文件 → SPA 回退**返回 index.html**（实测 `Content-Type: text/html`、974 B）→ 浏览器按 ES module 加载失败：

```
Failed to load module script: Expected a JavaScript-or-Wasm module script but the server
responded with a MIME type of "text/html".
```

全站协议页（`/merchantSettled/*`、`/merchantTransaction/*`、`/attractInvestment/*`、`/other/*` 共 30 余页）**都打不开**，只有 `/index` 列表页正常。

> 这与本技能已记载的 Vite「子路径 base 烘焙」事故**是同一类错误**：相对路径 + 服务端 SPA 回退 = 白屏。

**修法（最小改动，不动构建产物）**：`index.html` 里 4 处相对引用改为绝对路径。

| 项 | 值 |
|---|---|
| 线上文件 | `D:\www\yjk\web\agreement\index.html` |
| 改动 | `./logo.png`→`/logo.png`；`./favicon.ico`→`/favicon.ico`；`./assets/index-D51PlIMn.js`→`/assets/…`；`./assets/index-DfEreUqa.css`→`/assets/…` |
| 改前 | 982 B　SHA256 `AC9805F5A02E24F9…A7CD4F9A`（`./assets` 命中 2） |
| 改后 | 978 B　SHA256 `1F9627F2A18E05DE…0E37485C`（`./assets` 命中 0） |
| 备份 | `D:\www\yjk\web\agreement\_bak-agreefix-20261008-171633\` |

**真浏览器复验**（同一个探针，改前/改后对比）：

| 路由 | 改前 | 改后 |
|---|---|---|
| `/merchantSettled/two`《元健康隐私协议》 | 正文 **0 字**（白屏） | **17,137 字**，含「所有者"**北京数信商科技服务有限公司**"…与拟在元健康注册的用户…共同缔结」 |

## 六、本次踩到的四个坑（都已沉淀进技能）

| # | 坑 | 现象 | 正确做法 |
|---|---|---|---|
| 1 | **载荷托管成 `.ps1` 会被服务器当二进制** | MinIO 直传 `.ps1` → 服务器端 `Invoke-WebRequest` 拿到 `byte[]` → 落盘成 `"36 69 114 …"` 十进制字节序列 → `UnexpectedToken` | 载荷**一律托管成 `.txt`**（`text/plain`），服务器端才会拿到字符串 |
| 2 | **dpaste 会在服务器抓取时 429** | 投递回执 `OK`，但 agent 日志只有 `ERR (429)` → **任务根本没执行**，白等 | 载荷走 MinIO（`.txt`）；判断"是否真的跑了"看 agent 日志的 RUN/DONE |
| 3 | **PS 变量名大小写不敏感（第二次踩）** | `$new = "<路径>"` 把实体串 `$NEW` 覆盖掉 → 内容校验 `NEW_NEW_HITS=0` 伪失败 | 命名**绝不只靠大小写区分**；实体串统一 `$ENT_OLD`/`$ENT_NEW`，路径用 `$srcFile` |
| 4 | **命令行参数模式下的换行续行不成立** | `A ('a' + $x` ⏎ `+ 'b')` → `表达式中缺少右括号` | 这类拼接**必须写在一行** |

另：报告通道再加一条经验 —— **站点 `web/` 下的持久报告文件必须做"陈旧判定"**（读到的内容与本轮投递前的快照相同 = 上一轮的报告），否则会秒回上一轮结果。
