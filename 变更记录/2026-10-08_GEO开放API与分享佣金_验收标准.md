## 四、Ⅲ 分享佣金账本（**本期只记账、不打款**）

### 前置事实（必须先说清）
**目前没有"推广用户收益"这个东西可分成** —— `shuzi.yuanjk.cn` **还没有订阅与支付**。要产生佣金，先得有订单与收款闭环。两条路：
- **路线甲（推荐）**：复用元健康商城（同主体、已有支付通道与订单），AI 顾问订阅作为商城的商品 → 佣金从商城订单算；
- **路线乙**：AI 顾问自建订阅与支付 → 需支付资质、结算与税务合规，周期长。

### 本期实现（账本，与路线无关，先把口径与算法钉死）
| # | 验收标准 |
|---|---|
| 1 | 归因绑定：新用户注册携带邀请码 → `referral(referrer, referee, bound_at)` **一次性绑定、不可改绑**（除后台人工并留痕） |
| 2 | 计佣：订单**支付成功**后写 `commission_ledger` 1 条，金额 = `round(实付金额 × 30%, 2)`；状态 `pending` |
| 3 | 续费同步：同一订阅的**每次续费**订单同样计佣（同 30%），**不重复计佣**（同订单号幂等） |
| 4 | 退款冲正：整单退款 → 对应佣金 `reversed`；部分退款 → 按比例冲减；账户累计同步变化 |
| 5 | 风控：自推自买（同 member / 同设备 / 同支付账号）→ **拒绝计佣**并标记人工复核 |
| 6 | 用户端：可见「累计收益 / 待结算 / 已结算 / 明细」；后台可见全量流水与异常标记 |
| 7 | 结算口径：T+7 结算（订单过退款期），提现**本期不开放**（按钮置灰 + 说明"待开通"） |
| 8 | 合规自检：**仅一级分销**、按**实际成交**计佣、**无入门费/无按人头收费**（脚本与文档双断言，规避传销红线） |

### ⚠️ 请师父先定这 4 项（涉及钱，我不敢自行拍板）
1. **30% 的基数**：订单**实付金额**（含支付手续费与税）？还是扣费后的净额？（我默认按**实付金额**，请确认）
2. **续费同步的范围**：永久同步？还是限首年/前 N 次续费？
3. **结算与提现**：T+7 是否合适？提现门槛、税务代扣方式（个人劳务报酬代扣？）
4. **走甲还是乙**：佣金从**商城订单**算（甲），还是 AI 顾问**自建订阅**（乙）？
