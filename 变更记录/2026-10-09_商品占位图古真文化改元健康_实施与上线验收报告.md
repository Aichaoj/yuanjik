## 二、根因（这类图为什么会显示古真文化）

1. C 端商品图统一走组件 `components/easy-loadimage/easy-loadimage.vue`（含 `v1/loadimage`、`v1/waterfall`），
   其占位图写死为：
   ```js
   loading: require('@/static/easy-loadimage/loading.jpg'),   // ← 这张图上就是「古真文化 gztsc.cn」
   // loadfail: require('@/static/easy-loadimage/loadfail.png'),   ← 失败图被注释掉了
   ```
2. 模板里**两种状态都用它**：`v-show="!showImg&&!isLoadError"`（加载中）与 `v-else-if="isLoadError"`（**加载失败**）。
   ⇒ 图片没加载出来时，**会一直显示这张古真文化图**。
3. 而线上确实有大量图加载不出来：`config/icon.js` 里那批老 MinIO 资源（`System/2024/…`，含分类兜底图、暂无数据图、默认头像、LOGO 等 **40+ 个 key**）**全部 404**（新库建站时未迁移），构建产物 `static/js/index.72471bf0.js` 仍在引用它们。
   **所以师父在商品列表/详情里看到的"默认图片"就是这张古真文化占位图。**
