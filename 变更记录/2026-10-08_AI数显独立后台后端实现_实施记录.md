## 四、安全与脱敏（硬要求逐条落地）

| 要求 | 实现 |
|---|---|
| 口令只从环境变量读、绝不写死 | `ADMIN_PASSWORD_ENV='YJK_ADMIN_PASSWORD'`；缺失即 `AdminApiDisabled`（连表都不建、路由不注册）。源码内无任何默认口令（测试断言） |
| 标准库比对 | `hmac.compare_digest(password, env_password)`；令牌摘要比对同样用 `compare_digest` |
| 失败 5 次锁 15 分钟（按 IP） | `Limit(5, 900)` 同口径 + `40000 RATE_LIMITED`（HTTP 429），返回 `detail.remaining_sec`；锁定期内**即使口令正确**也拒 |
| 后台令牌独立于 C 端 | 独立内存表（只存 SHA-256 摘要）、独立校验 `_require_admin`、TTL 2 小时；**双向实测**：后台令牌调 C 端 401、C 端令牌调后台 401 |
| 所有 `/v1/admin/*`（除 login）必须校验 | 无 / 错 / 过期令牌 → 401（`20000` / `20001`） |
| 审计（操作者/动作/目标/时间/IP） | 白名单动作 `login_ok/login_fail/login_locked/user_detail/ban/unban/export`；**看一次详情恰好 +1 条**；查看审计本身不写审计 |
| 脱敏（验收 #4 字段级） | 生辰**只到日** + 出生地城市；**不回**精确时刻/经纬度；体征与病史**未采集**（只回布尔标记，无任何数值/原文）；打卡只回日期与通道数；出口自检 `_assert_no_secrets()`（fail-closed，命中禁止字段或原始出生串即 500 不出数据） |
| 金额用整数分 | 本模块**不涉及金额**（佣金账本在 `pay.py`，未改动） |
| 注释一律中文 / 禁词 | 全部中文注释；10 个合规禁词在 `admin_api.py`、`social.py` 中均不出现（测试断言） |

## 六、未验证项（如实声明）

1. **未部署线上**：全部为本机（`127.0.0.1:15088`）实测；`shuzi.yuanjk.cn` 的上传与线上回归未做。
2. **后台令牌只存内存**：进程重启即失效（需重新登录）；多实例不共享令牌（本站单机定位）。
3. **未做压测**：后台接口与 C 端共用 `GLOBAL_LOCK`，串行执行；未测并发与大数据量（当前全表进内存分页）。
4. **封禁范围**：只停用社交（`/v1/friends*`）；登录/建档/打卡/指数/支付**不受影响**（按变更单「社交功能停用」口径）。
5. **两套后台闸门并存**：`pay.py` 既有的 `/v1/admin/commission` 仍用 `SHUZI_ADMIN_TOKEN`（未改动、未统一登录）。
6. **出生地城市**由前端正本 `web/app.js` 的城市表反查（容差 0.35°）；该表缺失时回 `null`，绝不猜城市。
7. **锁定按来源 IP**：若部署在反向代理后且未透传真实来源 IP，同代理用户会被一起锁定（部署时需确认 `client_ip` 来源）。
8. 浏览器实测依赖**系统 Python 的 Playwright**；便携运行时无 Playwright 时该项自动 SKIP（不计失败）。
