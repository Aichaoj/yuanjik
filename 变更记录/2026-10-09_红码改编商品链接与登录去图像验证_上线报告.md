## 二、第③条：登录去掉图像验证（已上线）

**根因**：商城登录（`UserService.LoginV2` 与 `AuthService.SignIn`）强制校验**图形验证码**：`CaptchaService.Validate` 从 Redis 取 `captcha:<key>` 与用户输入比对；平台**没有开关**，且 Captcha 凭据（Aliyun）本身也是 TBD ⇒ 所有人都登不进去。

**做法（不改接口契约、可一键回退）**：

| 层 | 改动 |
|---|---|
| 服务端源码 | `UserService.cs` / `AuthService.cs` 的验证码三段检查全部包进 **`if (!_configuration.GetValue<bool>("SkipLoginCaptcha"))`**（开关关闭时行为与原来**逐字一致**） |
| 重编译 | 服务器上 **.NET SDK 8.0.409** 就地 `dotnet build Avatar.Application -c Release` → **0 错误**（5,567 警告为既有）；产出 `Avatar.Application.dll`（2,338,304B，`1F0830FD…`） |
| 换 DLL | **先停 `YJKApi` → 再换 DLL → 起服务**（首次尝试直接在运行中覆盖被文件锁挡住，已自动回滚；修正后一次成功） |
| 配置 | `D:\www\yjk\api\appsettings.json` 增加 **`"SkipLoginCaptcha": true`**（改回 `false` 即恢复验证码，**无需重编译**） |
| 前端 | ①删掉密码登录页的前端校验 `if(!t.loginForm.captchaValue)return ...请输入验证码...`；②`index.html` 注入作用域样式 `#yjk-login-captcha-off`：`.item-image-box[data-v-346bbb0c],.item-input.width-240.wdih[data-v-346bbb0c]{display:none!important}` |

**验证证据**：

| 项 | 实测 |
|---|---|
| 服务端（服务器本机） | `LOGIN_NO_CAPTCHA_HTTP=200`，返回 token 与 `"userName":"夏志兵"`（**导入用户**） |
| 公网接口（本机） | `POST https://api.yuanjk.cn/user/login/v2`，`CaptchaKey/CaptchaValue` 全空 → **`success:true`**；另用 `15319922277` 复测同样成功 ✅ |
| 前端 UI（真浏览器 390px） | 密码登录页 `/pages/user_login/login/pwd/index`：验证码**图容器 display:none（0×0）**、验证码**输入容器 display:none（0×0）**；页面文案只剩「手机号/用户名、密码、忘记密码、登录、验证码登录」 |
| 未完成项（如实） | 脚本化「填号→点登录」在无头环境受**自定义键盘 + 协议勾选**影响，未能跑通提交（提示为「请先阅读并同意协议」，**已不是验证码问题**）；建议师父真机点一次确认 |

**回退**：

| 对象 | 回退 |
|---|---|
| DLL | `Copy-Item D:\www\yjk\pkgs\_bak-captcha-20261009-181750\Avatar.Application.dll D:\www\yjk\api\ -Force`（先停服务再拷，后启动） |
| 配置 | `appsettings.json` 用同目录备份还原，或把 `SkipLoginCaptcha` 改为 `false` → 重启 `YJKApi` |
| 前端 | `D:\www\yjk\pkgs\_bak-h5captcha-20261009-181906\{pages-user_login-login-pwd-index.b6a7372a.js, index.html}` 拷回 `D:\www\yjk\web\h5\` 对应位置 |
