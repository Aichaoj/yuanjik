结论：不是球没居中，是**围着球飞的八颗流星整体偏了 9 px**，所以看上去球的“中心点”不在圆环中心。

## 二、根因（一行 CSS）

```css
.cosmic .cm { position:absolute; left:50%; top:50%; width:18px; height:2px; }
@keyframes cmIn { … transform: rotate(var(--a)) translateX(150px) … }
```

`left/top:50%` 钉住的是这条 18×2 小横条的**左上角**，而 `transform-origin` 默认是它**自己的中心**。
于是每颗流星的中心 = 容器中心 + **(9, 1)** + 旋转后的半径向量；八颗共用的环心必然右移 9、下移 1。
（旧写法没补半个身位，纯几何错位，跟动画时间无关。）

## 三、改法
